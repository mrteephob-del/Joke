# ระบบเว็บแอปพลิเคชันสั่งอาหารออนไลน์ "ร้านข้าวต้มนายเจ๊ก วงเวียนตาคลี" 🍲
> ระบบสั่งอาหารออนไลน์บน **LINE LIFF App** เชื่อมต่อฐานข้อมูล **Google Sheets** แบบ Real-time ผ่าน **Google Apps Script (GAS)**
> ดีไซน์ใหม่ **Minimalist Light Mode (สบายตา คลีน ใช้งานง่าย)** พร้อมระบบชำระเงิน **PromptPay QR Code (064-279-3664)** และรองรับ **รูปภาพอาหารจาก Google Sheets**

---

## 🌟 ฟังก์ชันใหม่และจุดเด่นของระบบ (Key Features v2)

1. **🎨 UX/UI Minimalist Light Mode:**
   - ธีมสีสว่าง คลีน สบายตา สไตล์ Modern Japanese-Thai Dining & Cafe
   - ใช้งานง่ายบนมือถือ ตัวหนังสือคมชัด อ่านง่าย จัดวางเป็นสัดส่วน
   - การ์ดอาหารแสดงรูปภาพคมชัด พร้อมระบบแสดงภาพสำรอง (Placeholder) อัตโนมัติเมื่อยังไม่มีรูป

2. **🔔 หน้าจอห้องครัว & แคชเชียร์ (Kitchen Display System - KDS):**
   - เปิดหน้าร้านทิ้งไว้บนแท็บเล็ต iPad/Android หรือมือถือที่เคาน์เตอร์
   - **ระบบเสียงกระดิ่งแจ้งเตือนทันที (Order Chime 🔔):** เมื่อมีออเดอร์ใหม่เข้ามา เสียงกระดิ่งจะดังเตือนพนักงานทันที
   - ซิงค์ออเดอร์จาก Google Sheets อัตโนมัติทุก 6 วินาที
   - มีเช็กลิสต์รายการอาหารให้พ่อครัวติ๊กตาม พร้อมไฮไลต์หมายเหตุพิเศษ (เช่น ไม่เผ็ด, ไม่ใส่ผัก)
   - มีปุ่มกดเปลี่ยนสถานะ: `[รับออเดอร์/เริ่มปรุง]` ➔ `[ปรุงเสร็จแล้ว]` ➔ `[เสร็จสิ้น]` ซิงค์กลับไปยัง Google Sheets และหน้าจอลูกค้าทันที

3. **💳 ระบบชำระเงิน 2 ช่องทาง (Payment Methods):**
   - **📱 สแกน QR พร้อมเพย์ (PromptPay 064-279-3664):**
     - สร้าง QR Code พร้อมเพย์ตามมาตรฐาน EMVCo อัตโนมัติระบุยอดเงินตรงกับบิล ไม่ต้องให้ลูกค้าพิมพ์ยอดเอง ป้องกันการโอนผิด
     - ปุ่มดาวน์โหลด/บันทึกภาพ QR Code ลงเครื่อง
     - แสดงรายละเอียดเบอร์พร้อมเพย์และชื่อบัญชีร้านชัดเจน
   - **💵 ชำระเงินสด (Cash on Delivery / Pay at Shop):**
     - รับที่ร้าน: ชำระที่เคาน์เตอร์เมื่อมารับอาหาร
     - เดลิเวอรี: ชำระกับพนักงานส่งเมื่อได้รับอาหาร
   - บันทึกวิธีชำระเงินลงใน Google Sheets ชีต `Orders` ชัดเจน

3. **🖼️ รองรับการใส่รูปภาพอาหารในชีต `Menu`:**
   - ในชีต `Menu` มีคอลัมน์ **`รูปภาพ (Image URL)`** (คอลัมน์ J)
   - **รองรับลิงก์ Google Drive:** สามารถคัดลอกลิงก์แชร์ของรูปภาพจาก Google Drive มาวางได้ทันที ระบบจะแปลงเป็น Direct Image Link ให้อัตโนมัติ!
   - รองรับลิงก์รูปภาพจากเว็บทั่วไป (Imgur, Cloudinary, เว็บไซต์ ฯลฯ)

4. **🚀 ระบบคิวและการบันทึกออเดอร์ตามจริง (Real Order & Queue):**
   - ออกหมายเลขคิวรายวัน (`Q01`, `Q02`, `Q03`...) ตามจำนวนออเดอร์ที่สั่งจริงในวันนั้น
   - บันทึกข้อมูลลง Google Sheets ทันที: เลขที่ออเดอร์, วันเวลา, ลูกค้า, เบอร์โทร, รูปแบบการรับ, พิกัด GPS, ระยะทาง, ค่าส่ง, ยอดรวม, วิธีชำระเงิน, รายการอาหาร, สถานะออเดอร์
   - ระบบป้องกันปัญหา CORS อัตโนมัติด้วย Fallback Mechanism (ทำงานได้แน่นอน 100% บนมือถือและ LINE In-App Browser)

5. **🛵 บริการจัดส่งและคำนวณค่าส่ง:**
   - ปุ่มปักหมุด GPS ดึงตำแหน่งปัจจุบัน
   - คำนวณระยะทางจากวงเวียนตาคลี
   - **0 - 3 กิโลเมตรแรก: ส่งฟรี (0 บาท)**
   - **เกิน 3 กิโลเมตร: กิโลเมตรละ 5 บาท**

## 📋 วิธีเพิ่มรูปภาพอาหารใน Google Sheets

1. เปิดไฟล์ Google Sheets ของร้าน
2. ไปที่ชีต **`Menu`**
3. ที่คอลัมน์ **J** (หัวตารางคือ **`รูปภาพ (Image URL)`**)
4. ใส่ลิงก์รูปภาพที่ต้องการ:
   - **กรณีใช้ Google Drive:**
     - อัปโหลดรูปภาพขึ้น Google Drive
     - คลิกขวาที่รูป > **แชร์ (Share)** > เปลี่ยนสิทธิ์เป็น **"ทุกคนที่มีลิงก์ (Anyone with the link)"**
     - คลิก **คัดลอกลิงก์ (Copy link)** แล้วนำมาวางในช่องของเมนูนั้นๆ
     - *ระบบเว็บจะแปลงลิงก์และแสดงรูปภาพให้อัตโนมัติทันที!*
   - **กรณีใช้เว็บฝากรูปอื่น:** สามารถคัดลอก URL ของรูปภาพ (เช่น `https://.../food.jpg`) มาวางได้ทันที

## ⚙️ การอัปเดตโค้ดใน Google Apps Script (GAS)

เนื่องจากมีการเพิ่มคอลัมน์รูปภาพและระบบชำระเงิน:

1. เปิด Google Sheets > **ส่วนขยาย (Extensions)** > **Apps Script**
2. คัดลอกโค้ดทั้งหมดจาก [`backend/Code.gs`](file:///Users/teephobwirachowatin/work/Joke/backend/Code.gs) ไปวางแทนที่โค้ดเดิม
3. กดปุ่ม **บันทึก (Save)**
4. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)** > **จัดการการทำให้ใช้งานได้ (Manage deployments)**
5. คลิกไอคอน **แก้ไข (ดินสอ)** ที่รายการ Web app เดิม
6. ที่ช่องเวอร์ชัน เลือก **เวอร์ชันใหม่ (New version)** แล้วกด **ทำให้ใช้งานได้ (Deploy)**
*(การทำแบบนี้จะทำให้ได้ใช้ URL เดิม ไม่ต้องเปลี่ยน URL ใน `js/config.js`)*
