# ระบบเว็บแอปพลิเคชันสั่งอาหารออนไลน์ "ร้านข้าวต้มนายเจ๊ก วงเวียนตาคลี" 🍲
> ระบบสั่งอาหารออนไลน์บน **LINE LIFF App** เชื่อมต่อฐานข้อมูล **Google Sheets** แบบ Real-time ผ่าน **Google Apps Script (GAS)**

---

## 🌟 จุดเด่นของระบบ (Key Features)

1. **เปิดใช้งานบน LINE ได้ทันทีผ่าน LINE LIFF:**
   - ดึงชื่อและรูปโปรไฟล์ของลูกค้าจาก LINE อัตโนมัติ (`liff.getProfile()`)
   - ส่งข้อความสรุปใบเสร็จคำสั่งซื้อกลับเข้าห้องแชท LINE อัตโนมัติ (`liff.sendMessages()`)
2. **ระบบจัดการ 2 รูปแบบการรับอาหาร (Fulfillment Modes):**
   - **🛍️ มารับที่ร้าน (Takeaway / Pick-up):**
     - ระบุเวลารับอาหารล่วงหน้า (เช่น อีก 20 นาที, อีก 30 นาที หรือระบุเวลาเอง)
     - คำนวณลำดับคิวและแสดงสถานะคิวรอแบบเรียลไทม์
     - ฟรีค่าจัดส่ง (0 บาท)
   - **🛵 บริการจัดส่งถึงที่ (Delivery):**
     - ปักหมุดพิกัด GPS อัตโนมัติจากมือถือ และคำนวณระยะทางจากวงเวียนตาคลีผ่าน Haversine Formula
     - **เงื่อนไขคิดค่าส่งโปร่งใส:**
       - ระยะทาง **0 - 3 กิโลเมตรแรก: ส่งฟรี (0 บาท)**
       - ระยะทาง **เกิน 3 กิโลเมตร: คิดกิโลเมตรละ 5 บาท** (ปัดเศษขึ้นอย่างชัดเจน)
       - สามารถปรับแก้ระยะทางหรือพิมพ์ที่อยู่จัดส่งอย่างละเอียดได้
3. **ครบครัน 58+ รายการเมนูตามสั่งยอดนิยม:**
   - แบ่งหมวดหมู่ชัดเจน: เมนูทอด, ยำแซ่บ, ผัดร้อนๆ, ต้ม/แกง/ตุ๋น, ข้าว/เครื่องเคียง
   - ระบบตัวเลือกเนื้อสัตว์ (เช่น ผัดพริกแกง/ผัดกะเพรา: หมู/ไก่ 70.-, ทะเล/หมูกรอบ 100.-)
   - ช่องระบุหมายเหตุพิเศษในแต่ละจาน (เช่น ไม่เผ็ด, ไม่ใส่ผักชี, พิเศษ)
4. **Google Sheets เป็นฐานข้อมูลแบบ Full Two-Way Sync:**
   - แผ่นงาน `Menu`: เพิ่ม/ลด/แก้ไขราคา และสถานะ "พร้อมขาย / สินค้าหมด" ได้ทันที
   - แผ่นงาน `Orders`: บันทึกทุกคำสั่งซื้อพร้อมรหัสออเดอร์ (เช่น `JK-20261004-001`), หมายเลขคิว (`Q01`), พิกัด GPS, ระยะทาง, ค่าส่ง, ยอดรวม และสถานะการปรุง

## 🚀 ขั้นตอนการติดตั้งและเปิดใช้งาน (Setup Guide)

### ขั้นตอนที่ 1: การสร้างฐานข้อมูล Google Sheets และติดตั้ง Google Apps Script

1. ไปที่ [Google Sheets](https://sheets.new) เพื่อสร้างสเปรดชีตใหม่ ตั้งชื่อว่า **"ฐานข้อมูล ร้านข้าวต้มนายเจ๊ก"**
2. ที่แถบเมนูด้านบน เลือก **ส่วนขยาย (Extensions)** > **Apps Script**
3. ลบโค้ดเดิมในหน้าต่าง `Code.gs` ออกทั้งหมด
4. เปิดไฟล์ [`backend/Code.gs`](file:///Users/teephobwirachowatin/work/Joke/backend/Code.gs) ในโปรเจกต์นี้ แล้ว **คัดลอกโค้ดทั้งหมดไปวาง** ใน Apps Script
5. กดปุ่ม **บันทึก (Save)** (ไอคอนแผ่นดิสก์)
6. **รันการตั้งค่าเริ่มต้นอัตโนมัติ (Initial Setup):**
   - ที่แถบเครื่องมือด้านบน เลือกฟังก์ชัน **`initialSetup`**
   - กดปุ่ม **เรียกใช้ (Run)**
   - ในครั้งแรก Google จะขอสิทธิ์เข้าถึง (Authorization Required) ให้คลิก **ตรวจสอบสิทธิ์ (Review Permissions)** > เลือกบัญชีของคุณ > คลิก **ขั้นสูง (Advanced)** > คลิก **ไปที่... (ไม่ปลอดภัย) / Go to project (unsafe)** > คลิก **อนุญาต (Allow)**
   - รอจนขึ้นข้อความ *Execution completed*
   - เมื่อกลับไปดูที่ Google Sheets จะพบว่าระบบสร้างชีต `Menu` (พร้อมรายการอาหาร 58+ รายการครบถ้วน) และชีต `Orders` (พร้อมหัวตารางสวยงาม) ให้อัตโนมัติทันที!
7. **Deploy เป็น Web App API:**
   - ที่มุมขวาบน คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)**
   - คลิกไอคอนรูปฟันเฟือง เลือกประเภทเป็น **เว็บแอป (Web app)**
   - ตั้งค่าดังนี้:
     - **คำอธิบาย (Description):** `Khao Tom Nai Jek API v1`
     - **เรียกใช้ในฐานะ (Execute as):** `ฉัน (Me)`
     - **ผู้มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(สำคัญมาก เพื่อให้ LIFF ส่งข้อมูลได้)*
   - กดปุ่ม **ทำให้ใช้งานได้ (Deploy)**
   - **คัดลอก URL ของเว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec` เก็บไว้

### ขั้นตอนที่ 3: การสร้างและตั้งค่า LINE LIFF App

1. ไปที่ [LINE Developers Console](https://developers.line.biz/console/) แล้วเข้าสู่ระบบด้วยบัญชี LINE
2. สร้าง **Provider** (เช่น `ร้านข้าวต้มนายเจ๊ก`)
3. สร้าง Channel ใหม่ประเภท **LINE Login**
4. เข้าไปที่ Channel ที่สร้างไว้ คลิกแถบแท็บ **LIFF** แล้วคลิก **Add**
5. ตั้งค่า LIFF App:
   - **LIFF app name:** `ร้านข้าวต้มนายเจ๊ก สั่งอาหารออนไลน์`
   - **Size:** `Full` (เต็มหน้าจอมือถือ)
   - **Endpoint URL:** ใส่ URL ของเว็บไซต์ที่คุณนำโค้ดไปโฮสต์ (เช่น GitHub Pages, Vercel, Netlify, Cloudflare Pages หรือ ngrok สำหรับทดสอบ)
   - **Scopes:** ติ๊กเลือก `profile` และ `openid`
   - **Bot link feature:** เลือก `Normal` หรือ `Aggressive` (ตามต้องการ)
6. คลิก **Add** ระบบจะสร้าง **LIFF ID** ให้ (เช่น `2000123456-AbCdEfGh`)
7. นำ **LIFF ID** ไปใส่ในไฟล์ [`js/config.js`](file:///Users/teephobwirachowatin/work/Joke/js/config.js):
   ```javascript
   LIFF_ID: "2000123456-AbCdEfGh",
   ```
8. ตอนนี้ลูกค้าสามารถสั่งอาหารผ่านลิงก์ LIFF เช่น `https://liff.line.me/2000123456-AbCdEfGh` บน LINE ได้ทันที!

## 🛠️ ทดสอบใช้งานในเครื่อง (Local Testing)

ระบบถูกออกแบบมาให้มี **Fallback & Standalone Mode** สามารถเปิดทดสอบบน Browser ทั่วไปได้ทันทีโดยไม่ต้องเปิดใน LINE:

1. เปิด Terminal ในโฟลเดอร์โปรเจกต์
2. สั่งรัน Local Server:
   ```bash
   python3 -m http.server 8080
   ```
3. เปิดเบราว์เซอร์ไปที่ `http://localhost:8080/`
4. ทดสอบ:
   - ลองสลับระหว่าง "มารับที่ร้าน" และ "เดลิเวอรี"
   - ลองป้อนระยะทาง เช่น 5 กม. ระบบจะแสดงค่าส่ง 10 บาท (ฟรี 3 กม. แรก + เกิน 2 กม. x 5 บ.)
   - ลองป้อนระยะทาง 2.5 กม. ระบบจะแสดง "ส่งฟรี 0 บาท"
   - กดปุ่ม "เลือก" เมนู "ผัดกระเพรา" หรือ "ผัดพริกแกง" เพื่อเลือกเนื้อสัตว์ (หมูกรอบ / ทะเล / หมู / ไก่)
   - กดดูตะกร้า และกดยืนยันสั่งซื้อ เพื่อรับหมายเลขคิว `Q01`, `Q02`...

### 2. แผ่นงาน `Orders` (ประวัติการสั่งซื้อ)
- **เลขที่ออเดอร์:** เช่น `JK-20261004-001`
- **คิวที่:** เช่น `Q01`, `Q02` (รีเซ็ตนับใหม่ทุกวัน)
- **วันเวลาที่สั่ง:** วันที่และเวลาในประเทศไทย
- **LINE User ID:** ID ผู้ใช้ LINE ของลูกค้า
- **ชื่อลูกค้า:** ชื่อที่ดึงจาก LINE หรือที่ลูกค้ากรอก
- **เบอร์โทรติดต่อ:** เบอร์โทร 10 หลัก
- **รูปแบบการรับ:** `รับหน้าร้าน` หรือ `เดลิเวอรี`
- **เวลานัดรับ / ที่อยู่จัดส่ง:** เช่น `รับเวลา อีก 20 นาที` หรือ ที่อยู่จัดส่ง
- **พิกัด GPS:** ละติจูด, ลองจิจูด จากเครื่องลูกค้า
- **ระยะทาง (กม.):** ระยะทางคำนวณจริงจากวงเวียนตาคลี
- **ค่าจัดส่ง (บาท):** คำนวณตามเงื่อนไข (0-3 กม. แรก 0 บาท, เกิน 3 กม. คิด 5 บ./กม.)
- **ยอดรวมอาหาร & ยอดชำระสุทธิ:** คำนวณสรุปชัดเจน
- **รายการอาหาร:** สรุปรายการอาหารแบบอ่านง่าย
- **สถานะออเดอร์:** `รอยืนยัน`, `กำลังปรุง`, `พร้อมส่ง/รับ`, `สำเร็จ`, `ยกเลิก`
